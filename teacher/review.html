Q: Explain the time complexity of accessing an element in an array by its index.
The time complexity of accessing an element in an array by its index is O(1) or constant time. This is because arrays are allocated in contiguous memory blocks. The memory address of any element can be calculated directly using the base address of the array, the index, and the size of a single element.

Q: What is the difference between RAM and ROM?
RAM (Random Access Memory) is volatile memory used for temporary storage while the computer is running. Data is lost when power is off. ROM (Read-Only Memory) is non-volatile memory used to store firmware. Data is retained even without power.
Marks: 10
Difficulty: Easy
Keywords: Volatile, Non-volatile, Temporary, Firmware
